# Greenfield / demo templates

Skeleton layout for **scratch** generation demos — not sealed Castra Vetera finals.

Sealed Magos / literary / state packs live under [`cogitator-results/`](../../cogitator-results/).  
Working scratch (if used) stays under [`out/`](../../out/).

## Expected sealed body pack shape

```text
<body-slug>/
  magos.md
  literary.md
  state.json
```

## Expected sealed system pack shape

```text
systems/<system-slug>/
  system.json
  system.md          # optional
```

## This folder

| Path | Role |
|------|------|
| `body/` | Drop example Magos stubs / greenfield body templates here |
| `system/` | Drop example system.json stubs here |

Do **not** put Castra Vetera mesh finals here — those belong in `cogitator-results/`.
